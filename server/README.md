# Wordle для Twitch

Сервер обрабатывает чат Twitch: однословные сообщения подходящей длины становятся попытками в активной игре.
Слова берутся из `cows/words.txt` и `cows/singular.txt`.

Вся игра живёт на одной странице: `http://localhost:3123/` — локальная игра, живая доска Twitch,
вход через Twitch и админ-панель. Отдельной страницы `board.html` больше нет (старый адрес открывает
то же самое).

## Возможности
- Создаётся отдельная игра: сервер выбирает слово из словаря или можно задать своё
- Только сообщения из чата канала считаются попытками
- Вход через Twitch: сервер запоминает всех, кто авторизовался, и выдаёт им право вручную
- Авторизация в чате: только подписчики, модераторы/VIP/владелец канала, одобренные пользователи либо все
- Живая доска в браузере с обновлением через SSE
- Лучшие и последние попытки, счётчики отклонённых сообщений
- Можно добавлять попытки вручную через админ-панель
- Токен и настройки сохраняются в `server/data/settings.local.json` (не попадают в git)
- Реестр пользователей и сессии — `server/data/users.json` (не попадает в git)

## Быстрый старт
1. Запустить сервер: `server/start-server.cmd` или `cd server && node server.js`
2. Открыть `http://localhost:3123/`
3. В админ-панели вписать админ-ключ (`admin` по умолчанию), ник и OAuth-токен бота с правом `chat:read`
4. Создать игру — доска сразу начнёт принимать сообщения из чата

## Вход через Twitch (для игроков)
Игрок нажимает «Войти через Twitch» на странице. Сервер:
1. проверяет токен через `https://id.twitch.tv/oauth2/validate`,
2. сверяет `client_id` с указанным в настройках,
3. запоминает игрока в `server/data/users.json` и выдаёт ему сессию (браузер хранит её в localStorage).

Пока игрок не получил право (одобрение админа в панели или вручную по нику), его попытки в игре
отклоняются с кодом 403.

Чтобы включить вход, нужно создать приложение на https://dev.twitch.tv/console/apps и вписать в
админ-панели:
- **Client ID** приложения,
- **Redirect URI** — адрес страницы с входом, по умолчанию `http://localhost:3123/wordle/wordle.html`
  (он же должен быть прописан в приложении Twitch),
- режим доступа `approved`.

Токен бота для чтения чата — отдельный, с правом `chat:read`.

## Как получить OAuth-токен Twitch (chat:read)
Нужен токен с правом `chat:read`.

Вариант 1 — Twitch Token Generator (самый простой):
1. Открыть https://twitchtokengenerator.com/
2. Выбрать `Custom Scope Token`
3. Поставить галочку `chat:read`
4. Нажать `Generate Token` и авторизоваться
5. Скопировать `Access Token` (без `oauth:` префикса или с ним — сервер сам уберёт)

Вариант 2 — Twitch CLI / dev.twitch.tv:
1. Создать приложение на https://dev.twitch.tv/console/apps
2. Получить токен через OAuth с scope `chat:read`

Вставить токен в админ-панели. Ник — ваш логин Twitch (нижним регистром).

## Режимы доступа
- `approved` — только те, кому админ выдал право в панели (по умолчанию)
- `subscribers` — подписчики, основатели, модераторы, VIP, владелец канала
- `whitelist` — только пользователи из белого списка (+ владелец)
- `all` — все (только для теста)

## API
- `GET /api/status` — статус сервера
- `GET /api/config` — настройки: режимы доступа, есть ли Client ID, статистика пользователей
- `POST /api/games` — создать игру (требует `X-Admin-Key`)
- `GET /api/games` — список игр
- `POST /api/games/:id/guess` — попытка (админ — вручную, игрок — по сессии `X-Session-Token` и одобрению)
- `POST /api/games/:id/stop` — остановить игру
- `GET /api/events` — SSE-поток обновлений
- `GET /api/auth/twitch` — параметры входа (Client ID, redirect URI, scope)
- `POST /api/auth/twitch/login` — обмен токена Twitch на сессию
- `GET /api/auth/me` — текущий пользователь по `X-Session-Token`
- `POST /api/auth/logout` — выйти
- `GET /api/admin/users` — список всех, кто авторизовался через Twitch (требует `X-Admin-Key`)
- `POST /api/admin/users/approve` — выдать или забрать право (`{ id | login, approved }`)
